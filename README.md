# Landing Page Starter

Simple static landing page scaffold using Bootstrap (CDN) and a small custom stylesheet.

Files created:
- `index.html` — main landing page
- `styles/custom.css` — custom brand overrides
- `assets/logo.svg` — placeholder logo

Open `index.html` in your browser to view the page. To run a local dev server with live reload, install `live-server` or `http-server`:

```bash
# Install live-server (optional)
npm install -g live-server

# Serve current folder on port 8080
live-server --port=8080
```

Customize `styles/custom.css` to change colors, fonts, and layout.
